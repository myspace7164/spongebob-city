# Sponge City presentation

Open [the animated HTML deck](../public/presentation.html) directly in a browser, or visit `/presentation.html` on the game server. Keep the presentation-media folder beside the HTML file when copying it. Slides, clips, still images and animations work offline from that bundle. External source links and the game launch require their usual destinations.

The first nine slides form an approximately three-and-a-half-minute pitch; the tenth is the sources and limits appendix. Slide 8 shows the level builder, which can build levels anywhere in the exported Basel map. Speaker notes and suggested timing are embedded in the deck as the single home for the script. Press N or click Notes to show them.

Use the arrow keys, Space, Page Up/Down, Home/End or the navigation buttons. F enters full screen. Pause motion disables animations; system reduced-motion settings are also respected. Print to PDF exports all ten slides in landscape. Slide 3 switches between actual gameplay and a diagram that transforms a sealed street into a sponge city. Short muted clips play only on the current slide; motion pause, reduced motion and printing use still images.

The geographic claim is deliberately scoped: eight real Basel location candidates today, with expansion to other cities worldwide as a future possibility. Public geodata is separate from illustrative gameplay coefficients and third-party game assets. Intended learning outcomes have not yet been evaluated in classrooms.

Before presenting, open the game in another tab, check the controls and rehearse the first nine slides. The deck remains available as a fallback if the game or network is unavailable.
