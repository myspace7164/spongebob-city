# Glossary

Domain terms used in the code and docs, one line each. Code names use these words. Add a term when it first appears in code; remove it when it's no longer used.

| Term | Meaning | Used in |
| ---- | ------- | ------- |
|      |         |         |

- Sponge city: a city that retains rain through vegetation, permeable soil and storage.
- Unsealing: replacing impermeable asphalt with ground that can absorb water.
- Useful water reuse: water delivered from the sponge into vegetation or storage; removing street water alone does not satisfy the mission.
- Surface water: rainwater on a plot that contributes to flood danger.
- Retained water: water currently held in soil and structures; reported separately from cumulative water delivered and deep infiltration.

- **Campaign:** four story levels; each advances when all current achievements are satisfied.
- **Runoff connection:** a directed roof/tank link to receiving ground or storage; roof water releases slowly and surface overflow follows the route.
- **Level checkpoint:** the city snapshot at level entry, used for retry without erasing completed levels.
